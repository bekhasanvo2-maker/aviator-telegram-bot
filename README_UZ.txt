AVIATOR STATISTIKA — TELEGRAM BOT (O‘zbekcha)

NIMA QILADI?
- /add 1.25 orqali raund natijalarini kiritasiz.
- /stats tarixiy statistikani hisoblaydi.
- /history oxirgi natijalarni ko‘rsatadi.
- /clear o‘zingiz kiritgan tarixni tozalaydi.
- Har bir Telegram foydalanuvchisining tarixi alohida saqlanadi.

MUHIM:
Bot keyingi Aviator raundini aniq bashorat qilmaydi. Oldingi natijalar keyingi raundni kafolatlamaydi. Botning o‘zi pul tikmaydi va hisobingizga kirmaydi.

TELEGRAMDA ISHLATISH:
1. Telegramda @BotFather ni oching.
2. /newbot yuboring va bot nomi hamda username tanlang.
3. BotFather bergan tokenni xavfsiz saqlang. Tokenni hech kimga yubormang.
4. Ushbu ZIPni kompyuterga yuklab, oching. Python 3.9+ o‘rnatilgan bo‘lsin.
5. Terminal/CMD ichida loyiha papkasiga kiring.
6. Tokenni environment variable qilib o‘rnating:

Windows PowerShell:
  $env:TELEGRAM_BOT_TOKEN="BOTFATHER_BERGAN_TOKEN"
  python bot.py

macOS/Linux:
  export TELEGRAM_BOT_TOKEN="BOTFATHER_BERGAN_TOKEN"
  python3 bot.py

7. Bot ishlashi uchun dastur ishlayotgan kompyuter/server internetga ulangan va o‘chiq bo‘lmasligi kerak.
   24/7 ishlatish uchun doimiy ishlaydigan hosting/server kerak bo‘ladi.

TELEGRAM BOTNI O‘ZIMIZDAN BEVOSITA JOYLASH:
ChatGPT sizning Telegram akkauntingizga kira olmaydi yoki BotFather’da sizning nomingizdan bot ocholmaydi. Tokenni chatga yozmang. Bu ZIP ishga tushirish uchun kod va yo‘riqnomani o‘z ichiga oladi.
